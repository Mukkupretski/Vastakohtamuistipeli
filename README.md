# Vastakohtamuistipeli

## Tiivistelmä

Peli on kuin normaali muistipeli pienellä lisähaasteella: tavoitteena ei ole löytää identtisiä pareja vaan vastakohtapareja!

## Teknologiat

- Projekti on rakennettu **React**-kirjastolla ja BuildToolina on **Vite**
- **Firebase** on käytössä hostauksessa ja **Firestore** tietokantana
